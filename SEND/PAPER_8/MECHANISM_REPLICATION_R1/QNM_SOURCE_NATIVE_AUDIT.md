# Source-native Kerr QNM audit

The installed `qnm` library was used with source-native remnant z-spin and remnant mass from metadata for SXS:BBH:0319, 0323, and 0320. No coefficient was fitted.

The observed h44-minus-h22 peak interval is 0.50–0.70M across the three events, while the `(2,2,0)` damping scale in initial-M units is approximately 11.74M. Therefore the peak interval is not itself a damping-time measurement; it is much shorter than one QNM damping time.

This is a consistency calculation only and does not identify the surface transient with a QNM or explain the RIUD memory law.
