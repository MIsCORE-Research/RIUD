# RIUD Papers I-IV Claim-Evidence Numerical Companion R1

This public companion contains frozen numerical sources, design and role locks, manifests, SHA-bound provenance, and verifier materials required to audit published claims in RIUD Papers I-IV.

It is a claim-evidence release, not a full computational reproduction archive. Large raw GWOSC products and non-essential runtime intermediates are not duplicated where not required for claim-level numerical verification. The Paper III 118,855-file runtime tree and all 13,000 controls are not duplicated here.

No scientific analysis, null generation, refitting, reselection, or holdout opening was performed to create this release. Paper I/II historical authority-file closure is exact: 340/340 expected authority files are SHA-verified, including 19 files recovered from existing original-byte copies.

Run python VERIFY_COMPANION.py from this directory to verify package-local evidence and hashes.
