# Release scope

Included: claim-level numerical sources, frozen design/role locks, manifests, source hashes, verifiers, and the compact Paper IV frozen package.

Excluded: full runtime trees, the Paper III 13,000-control intermediate tree, large raw GWOSC/PE inputs, temporary/cache/debug files, and untouched Holdout30 data. External public input references are listed in EXTERNAL_PUBLIC_INPUTS.md.

This companion does not claim source-to-final recomputation from raw data; it provides traceability and verification of frozen published numerical evidence.
